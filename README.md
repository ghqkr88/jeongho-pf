# 박정호 포트폴리오

새로운 경험과 여행을 좋아하는 취업 준비 중인 대학생 박정호의 포트폴리오입니다.

- 포트폴리오: `index.html` (소개 / 활동 / 자격 및 어학)
- 아침 뉴스 브리핑: `news/` (매일 07:00 경제·사회 뉴스 자동 수집)

## 아침 뉴스 브리핑

매일 아침 7시(KST)에 GitHub Actions 가 주요 언론사 RSS 에서 최근 24시간의 경제·사회 뉴스를 모아
`news/index.html` 한 페이지로 정리합니다.

- 경제 / 사회 두 칸으로 나눠 최신순 정렬, 같은 제목 기사는 하나로 합침
- 제목에 많이 나온 단어로 **오늘의 키워드** 표시
- 언론사별 필터 버튼, 모바일·다크 모드 지원
- 지난 14일치 브리핑은 `news/archive/` 에 보관

**보는 법**: GitHub Pages 를 켜 두었다면 `https://<아이디>.github.io/jeongho-pf/news/` 에서 볼 수 있습니다.

**직접 실행**: `python3 news/fetch_news.py` (표준 라이브러리만 사용, 설치 불필요)
옵션: `--hours 12` (최근 12시간만), `--keep 30` (30일치 보관)

**언론사 바꾸기**: `news/feeds.json` 에 RSS 주소를 추가하거나 지우면 됩니다.

**수동 실행**: 저장소 Actions 탭 → "아침 뉴스 브리핑" → Run workflow
